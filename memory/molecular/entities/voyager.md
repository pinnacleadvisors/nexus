# Voyager

Minecraft-domain LLM agent (NVIDIA, 2023). Introduced the iterative curriculum + automatic skill-library pattern: agent proposes its next learning task based on current capability gap, executes in environment, codifies successful behaviour as a reusable skill. Nexus absorbs the curriculum + skill-library mechanisms; rejects vector-DB-based skill retrieval (memory drift).
