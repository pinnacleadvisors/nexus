# OpenSwarm

Multi-agent orchestration framework (OpenAI experimental). Demonstrates lightweight agent handoff via shared message bus. Nexus uses Claude Code's native Agent Teams (CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1) instead but the handoff-via-shared-bus pattern is referenced for the upcoming swarm work in solopreneur-loop.
