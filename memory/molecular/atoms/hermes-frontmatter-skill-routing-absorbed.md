# Hermes frontmatter skill-routing (absorbed)

Hermes uses YAML frontmatter (Intent / Required Tools / Success Criteria) at the top of each SKILL.md as a lightweight router index. Absorbed into Nexus: existing .claude/skills/* already follow this pattern; skill-trainer writes new entries with the same 3-line YAML so the existing skill-router.sh hook discovers them.
