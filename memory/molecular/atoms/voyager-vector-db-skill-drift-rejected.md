# Voyager vector-DB skill drift (rejected)

Voyager's vector-DB-based skill retrieval suffers from similar-but-wrong matches as the skill set grows. Rejected: Nexus uses Hermes-style frontmatter routing instead — exact keyword + light semantic intent match against SKILL.md frontmatter, with the body opened on demand. No vector embeddings, no drift.
